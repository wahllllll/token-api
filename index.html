如何使用公益 API 导航

  1. 可以直接搜索站点名称、额度、模型或标签。
  2. 也可以点击顶部导航类型，筛选想要注册的站点。
  3. 查看状态、热度、稳定度和作者推荐后，点击“打开站点”。
  4. 显示“需科学上网”的站点，需要科学上网环境。
  5. 投稿、失效反馈和其它详情，请私信公众号。
